## [1.0.0] - 27 November 2026
### Added
- First release: a Loki Checkout add-on for the Czech Republic (CZ)
- Czech-specific labels for street, house number, addition, postcode and state in the billing and shipping address forms, with a postcode mask and placeholder
- A Czech address grid layout where the country field spans the full width

### Fixed
- Country-specific settings now actually apply to Czech addresses, because they use the new address-specific and country-specific layout handles
